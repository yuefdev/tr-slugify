# Contributing

Thanks for taking the time to help out.

## Reporting a bug

Open an issue with the input string, the options you passed, the slug you got and the slug you expected.

## Making a change

1. Fork the repo and create a branch from `main`.
2. Make your change. Keep the package dependency-free.
3. Add or update tests in `test/` for any behaviour change.
4. Run `npm test` and make sure everything passes (Node.js 18 or later).
5. If you add or change an option, update `README.md`, `index.d.ts` and `CHANGELOG.md`.
6. Open a pull request describing what changed and why.

## Style

The repo uses `.editorconfig`: two-space indentation, LF line endings, single quotes in JavaScript.
